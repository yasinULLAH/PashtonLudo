School Information

Fee Rules

Auto WhatsApp Fee Reminders

Off by default in the full version. When on, the software sends each unpaid challan's parent a WhatsApp reminder by itself at the three stages above — one reminder per stage per challan, and the stages stop the moment the fee is paid. Reminders are sent only while WhatsApp is Connected, only between 09:00 and 20:00, and anything missed is caught up the next time the software opens. Automatic reminders appear in Communication marked "Auto reminder". (Shown switched on here as a sample.)

Bank & Raast (printed on fee challans)

The challan QR is a real payable Raast QR built from these values in the full version. The QR in this demo is a sample and cannot be paid.

Manual WhatsApp (QR Scan)

Connect the school's own WhatsApp number by scanning a QR code with that phone. Pressing Connect opens a separate WhatsApp window showing WhatsApp Web's own QR code — scan it from the phone to link the number. Once connected, queued messages can be sent from the Communication page.

Status: Connected — 0300 1234567 (sample)

Shown Connected here as a sample. In the full version the number stays connected across restarts — no rescanning — and Disconnect performs a real logout.

Cloud API Fallback (Meta WhatsApp Business)

The school's own Meta WhatsApp Business credentials can be saved instead, and messages are then sent through Meta's official API.

Numbering Prefixes

Master Key (for Forgot Password)

Status: Master Key is set. It lets the admin reset a forgotten password, along with a UbaSoft Reset Code issued for this computer.
