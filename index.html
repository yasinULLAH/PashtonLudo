📖 Complete Factual Step-by-Step Setup Guide (Windows & Linux)

By default, Windows and macOS merge all plugged-in mice into a single cursor (`pointerId: 1`). To make your browser receive a separate `event.pointerId` for each physical mouse on a single laptop, follow these exact steps:

🪟 Method A: Windows (2, 3, or 4 Mice)
  1. Plug in 2, 3, or 4 USB/Wireless mice into your Windows laptop.
  2. Install and launch a multi-cursor driver utility such as TeamPlayer4 (by Dicolab/IdeaCom) or MouseMux.
  3. Enable Independent Native Pointer / Multi-Pointer Injection in the driver settings so each physical mouse gets its own colored cursor and unique Windows Pointer ID.
  4. Click "2 Mice", "3 Mice", or "4 Mice" above, then have each player click their respective colored box above with their own mouse.
🐧 Method B: Linux (Built-in Native XInput — No Extra Software Needed!)
  1. Plug in your extra mice and open a terminal. Run xinput list to see each mouse's device ID (e.g., id=12, id=13).
  2. Create an independent master cursor for each additional player:
    xinput create-master Player2 (and Player3, Player4)
  3. Run xinput list again to find the new Master Pointer ID (e.g., Player2 pointer [id=18]).
  4. Attach the physical mouse to its new master cursor:
    xinput reattach 12 18
  5. Now open this game in Chrome/Edge/Firefox and click each player's calibration box above!
🛡️ How Enforcement Works During Match:

• When it is Red's turn, only Red's calibrated mouse (`pointerId`) can click 🎲 Roll Dice, filter dice, or drag/tap Red's beads on the board.

• If Green, Yellow, or Blue tries to click the dice or touch any bead during Red's turn, their hardware `pointerId` is rejected with a warning banner.

• If a player's seat is left uncalibrated (`Unassigned`), any mouse is allowed for that seat as a safe fallback so you never get stuck.
